Wanderlust Explorer

Individual Website Project - Site Plan

1. Site Name

Name: Wanderlust Explorer

Reasoning: This name was selected because it captures the passion and spirit of traveling ("Wanderlust") combined with discovering new places ("Explorer"), making it ideal for a global tourism and travel attraction website.

Optional domain availability: wanderlust-explorer.org

2. Site Purpose

The site serves as a comprehensive digital guide and exploration hub for global tourism. It provides users with detailed information, imagery, ratings, and descriptions for at least 15 worldwide travel destinations, complete with dynamic filtering, sorting, a user review form, favorite bookmarking via local storage, and interactive modal dialogs.

3. Scenarios

Target audience questions that drive the content and features of the website:

  • What are some of the top-rated European destinations to visit during the summer?
  • How can I save my favorite travel destinations to view them later on my browser?

4. Color Scheme

The selected color palette reflects a modern, clean travel aesthetic:

  • Primary Color (#1A365D - Deep Navy): Used for headers, site titles, navigation bars, and primary buttons.
  • Secondary Color (#2B6CB0 - Ocean Blue): Used for subheadings, links, and card borders.
  • Accent Color (#ED8936 - Sunset Orange): Used for highlights, call-to-action badges, and interactive element states.
  • Background Color (#F7FAFC - Light Gray/Off-White): Used for page backgrounds and content card containers.

Note: This color scheme is applied exclusively throughout this site plan document.

5. Typography

The typography choices ensure high readability and a contemporary feel across all screen sizes:

  • Heading Font (Roboto, sans-serif): Applied to all main headings (h1, h2, h3) to give a bold, clean structure.
  • Body Font (Open Sans, sans-serif): Applied to all paragraph text, lists, and general descriptions for optimal legibility.
